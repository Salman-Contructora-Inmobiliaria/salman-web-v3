Cómo leer el resultado
Gemini configurado

`/api/health` devuelve `geminiConfigured: true`. La prueba de API debe devolver un texto de Salma.

Sin clave

La API devuelve 503. El laboratorio y el chat usan respuestas locales; la voz sigue funcionando.

Sin micrófono

Usa el campo de texto. La síntesis de voz y la API se prueban igual.
